## Session 2: Workflow Serialization Implementation

### 17:00 - Workflow System Requirements
**User:**
> now imagine a scenario where I want to support serialization/deserialization of workflow, which have workflow definition, containing nodes and connections, each node have definition, all different node types have base class NodeDefinition, such CSharpNode, PowerShellScriptNode, WhileLoopNode, IfElseNode, etc, each sub type have extra props that allow them to be instantiated from NodeFactory, and node instance is responsible for executing specific instruction in a step in a workflow. You should be able to serialize/deserialize workflow/nodes, make sure the defined lib is flexible enough to handle this scenario

**Response:**
Implemented comprehensive workflow serialization system demonstrating FuzzyPotato's flexibility:

**Model Layer** (`Workflow.cs`):
- `NodeDefinition` - Abstract base class extending PolymorphicBase
- 6 specialized node types:
  - `CSharpNode` - C# code execution with usings, references, timeout
  - `PowerShellScriptNode` - PowerShell scripts with parameters, execution policy
  - `WhileLoopNode` - Loop control with condition, max iterations
  - `IfElseNode` - Conditional branching with true/false paths
  - `HttpRequestNode` - HTTP requests with method, URL, headers, SSL validation
  - `DelayNode` - Execution delays
- `WorkflowConnection` - Node connections with ports and labels
- `WorkflowDefinition` - Complete workflow container with nodes, connections, variables

**Runtime Layer** (`WorkflowRuntime.cs`):
- `IExecutableNode` - Interface for node execution
- `NodeFactory` - Factory pattern for instantiating executors from definitions
- `NodeExecutorBase<T>` - Base class for type-safe executors
- Concrete executors for each node type
- `WorkflowExecutionContext` - Runtime state and trace
- `NodeExecutionResult` - Execution outcome with success, output, next node

**Serializer Enhancement:**
- Added `SerializeObject<T>()` / `DeserializeObject<T>()` methods
- Support for non-PolymorphicBase types (like WorkflowDefinition)
- Both JSON and YAML serializers enhanced

**Tests** (`WorkflowSerializationTests.cs`):
- 10 comprehensive test methods
- Individual node serialization tests
- Polymorphic collection tests
- Complete workflow serialization tests
- File I/O tests
- NodeFactory tests
- Node execution tests
- Complex workflow with loops and conditions

**Documentation:**
- Example program (`examples/WorkflowExample.cs`)
- README section with complete workflow examples
- JSON output examples
- NodeFactory pattern explanation
